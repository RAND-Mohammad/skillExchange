# Skill Exchange

Skill Exchange is an ASP.NET Web Forms application for sharing skills and sending exchange requests between users.

## Live website

http://randmohammad-001-site1.ltempurl.com/Login

## Main features

- User registration and login with role-based access.
- Create, read, update, and delete operations for skills.
- Skill exchange requests with acceptance or rejection.
- Email notifications through SMTP.
- Feedback and ratings after exchanges.
- Administrator dashboard for users, skills, requests, and feedback.
- Export administrative data to Excel, Word, and PDF.
- SQL Server database backup and restore verification.

## Technologies

- ASP.NET Web Forms
- C#
- SQL Server
- HTML, CSS, and JavaScript
- Gmail SMTP
- SmarterASP hosting

## Local configuration

`Web.config` is intentionally excluded from this repository because it contains database and SMTP credentials. Create your own local configuration file with your database connection string and SMTP settings before running the application.
